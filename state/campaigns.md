# Campaigns

One section per clipping campaign. `scripts/check.py --campaign state/campaigns.md` reads these keys
(first match in the file wins, so keep one active campaign at the top or pass a separate file per campaign):

min_seconds: 15
max_seconds: 60
required_hashtags: #GTA6
required_mention: @example

## Example campaign
- Creator: `<login>`
- Link: <campaign URL>
- Status: active / paused / out of budget (checked YYYY-MM-DD)
- Rules: what must be in the clip, caption and description. Copy them here word for word once you can see them.
